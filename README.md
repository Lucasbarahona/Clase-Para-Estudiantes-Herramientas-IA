# 📘 Uso Responsable de la IA para Estudiar

*Guía práctica para estudiantes sobre cómo utilizar la Inteligencia Artificial como herramienta de aprendizaje y no como reemplazo del pensamiento crítico.*

---
</div>

## 🚀 Descripción
Este proyecto contiene una presentación educativa enfocada en el uso responsable de herramientas de Inteligencia Artificial para estudiar, aprender y mejorar el rendimiento académico.

El objetivo principal es enseñar a estudiantes cómo aprovechar herramientas como **ChatGPT, Claude, Gemini y NotebookLM** de manera ética, efectiva y útil para potenciar el aprendizaje real.

---

## 🎯 Objetivos
- ✅ **Comprender** qué es la IA y cómo impacta la educación.
- ✅ **Aprender** técnicas prácticas para estudiar con IA.
- ✅ **Evitar** el mal uso de herramientas de IA.
- ✅ **Mejorar** la comprensión, el análisis y el pensamiento crítico.
- ✅ **Utilizar** prompts útiles para estudiar mejor.

### 🛠 Técnicas de estudio con IA

| Técnica | Descripción |
| :--- | :--- |
| **Explicaciones Simples** | Desglosar conceptos difíciles para entenderlos fácilmente. |
| **Resúmenes Automáticos** | Sintetizar textos largos conservando las ideas clave. |
| **Preguntas de Prueba** | Generación de cuestionarios para repasar. |
| **Corrección y Feedback** | Revisión de respuestas con sugerencias de mejora. |
| **Simulación de Profesor** | Entrenamiento con un evaluador estricto simulado por IA. |
| **Autoevaluaciones** | Medir el propio conocimiento con exámenes cortos. |

### 🤖 Herramientas mencionadas
> **ChatGPT** • **Claude** • **Google Gemini** • **NotebookLM** • **Perplexity** • **Grammarly** • **Notion**
